DESCRIPTION: Tumour growth inhibition model (Simeoni et al. 2004), 1-cmt IV PK (closed form, k and V fixed)

[LONGITUDINAL]
input = {k, V, lambda0, lambda1, k1, k2, w0}

PK:
Cc = pkmodel(V, k)

EQUATION:
t_0 = 0
x1_0 = w0
x2_0 = 0
x3_0 = 0
x4_0 = 0
w = x1 + x2 + x3 + x4
ddt_x1 = lambda0*x1/(1 + (lambda0/lambda1*w)^20)^(1/20) - k2*Cc*x1
ddt_x2 = k2*Cc*x1 - k1*x2
ddt_x3 = k1*(x2 - x3)
ddt_x4 = k1*(x3 - x4)

OUTPUT:
output = {w}
